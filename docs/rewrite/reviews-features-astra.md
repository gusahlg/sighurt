1. **High — Fullscreen hides the controls needed to recover from fullscreen (lane D).**  
   “Lists no surfaces” conflicts with the chrome contract: notices must remain visible, and the chrome draws internal pages and errors. `location.focus` would focus an invisible editor; with no listed surface, the GUI may have no usable chrome keyboard target. Escape from page fullscreen also leaves controls hidden when the user’s window fullscreen remains enabled. Keep an address/command surface available when focused, show notices and internal pages, and provide a trusted page-fullscreen indicator and exit control. See [extension.rs:30](/home/gusahlg/repos/sighurt/ui/sighurt-ui/src/extension.rs:30), [extension.rs:40](/home/gusahlg/repos/sighurt/ui/sighurt-ui/src/extension.rs:40), and [app.rs:731](/home/gusahlg/repos/sighurt/frontends/sighurt-gui/src/app.rs:731).

2. **High — A fullscreen notification does not establish permission or guarantee successful reversal (lane D).**  
   Checking only “activated within five seconds” allows a recently active background view to qualify. Acceptance must require the current document of the shown view, appropriate window focus, and a consumed activation; exiting must prevent immediate re-entry using the same activation. Define behavior when `ExitFullscreen` fails, the engine crashes, or no confirming event arrives. Restore browser controls independently of engine cooperation. The existing service contract explicitly scopes authority to documents and fails closed; “engines report facts” already accommodates facts that describe requests. The unverified WPE exit path must be proven before advertising support. See [services.rs:10](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/services.rs:10), [permissions.rs:47](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/permissions.rs:47), and [command_failed](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/state.rs:1601).

3. **High — Fullscreen needs separate desired, observed, and page-owned state (lane D).**  
   One observed window boolean cannot also remember the user’s toggle and a page’s temporary override. Two toggles before the compositor responds can both request `true`; a late configure can arrive after the page exits; a user toggle during page fullscreen has no defined meaning. Track user intent, the owning `(ViewId, DocumentGeneration)`, and observed window state separately. Specify denial and compositor-driven exit behavior. Also, the current host reports configuration changes only when size or scale changes: adding a fullscreen field without changing that comparison would miss state-only transitions. See [window.rs:363](/home/gusahlg/repos/sighurt/frontends/sighurt-wayland/src/window.rs:363).

4. **High — The Escape exception changes both command ownership and keystroke guarantees (lane D).**  
   A hardcoded core Escape handler contradicts [CLAUDE.md:230](/home/gusahlg/repos/sighurt/CLAUDE.md:230), and there is no named command for explicitly leaving page fullscreen. Calling it analogous to Ctrl+A in an editor does not resolve that distinction. A pre-keymap interception must also consume the release and repeats after fullscreen has already ended, without stealing a previously passed press. Those guarantees currently belong to `KeyState`. Add a named exit command; either expose fullscreen context to configuration or explicitly adopt a narrow safety override implemented through the same press tracking. Define its precedence over chrome editing and IME cancellation. See [keymap.rs:10](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/keymap.rs:10) and [keys.rs:296](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/keys.rs:296).

5. **High — `history.clear` and `site.forget` cannot promise deletion with the proposed persistence contract (lane C).**  
   The session writer deliberately makes a second instance read-only. Clearing that instance’s in-memory history would leave the file unchanged. In the owning instance, a 30-second debounce leaves deleted history recoverable after a crash; an older queued write must not restore it. `ForgetVisits` has no request identity or result channel to report any of this. The binding rule “never written when `remember = false`” also needs an explicit exception for requested deletion. Use an acknowledged deletion operation that supersedes pending saves, reports durable success or failure, and reports lock contention honestly. Define whether retained `.broken-*` files are covered. See [persistence.rs:20](/home/gusahlg/repos/sighurt/crates/sighurt-runtime/src/persistence.rs:20) and the existing [SiteDataOutcome durability contract](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/events.rs:347). Sharing the session lock requires one explicit owner whose lifetime covers both writers.

6. **High — Status text is not a safe “hovered link” API (lane A).**  
   `StatusTextChanged` means generic status text, “such as” a hovered link. The core truncates it to 16 KiB. An “open link” action could therefore navigate a shortened URL, interpret ordinary status text as a search, or use stale text from an earlier document. Merely exposing the field as page data does not fix those semantics. Introduce an optional, document-scoped link target whose URL is validated and dropped when oversized, never shortened. Construct typed commands from it; do not reinterpret page strings as command syntax or silently grant them unrestricted navigation authority. See [events.rs:134](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/events.rs:134), [state.rs:1838](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/state.rs:1838), and [permissions.rs:20](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/permissions.rs:20).

7. **High — Find IDs do not solve stale results unless adapters can associate callbacks with the original operation (lane B).**  
   Consider `Search(A) → Search(B) → late result(A)`. Labelling that callback with the adapter’s *current* search ID makes the core accept it as B. Ladybird’s existing shim callback carries only view/current/total; CEF’s callback has an identifier, but its exposed `find` call takes no caller-supplied identifier. The mapping needs a demonstrated adapter protocol. `Search` also lacks a document argument, while `Next`, `Previous`, and `Stop` lack both document and search identity. Stamp operations at their source, define cancellation/serialization where native APIs lack correlation, and reject stale results before coalescing. Otherwise an obsolete result can replace the valid pending result. Normalize partial results, unknown counts and index conventions too. See [Ladybird shim:647](/home/gusahlg/repos/sighurt/engines/sighurt-engine-ladybird/shim/shim.cpp:647), [CEF find:1488](/home/gusahlg/repos/sighurt/engines/sighurt-engine-cef/src/capi.rs:1488), and [CEF results:2366](/home/gusahlg/repos/sighurt/engines/sighurt-engine-cef/src/capi.rs:2366).

8. **High — The terminal find fallback is unreachable for Servo as specified (lane B).**  
   The design says the core never emits `Find` when the engine capability is false, then relies on the runtime intercepting that effect for Servo text mode. No effect reaches the hook. Moreover, returning only `bool` leaves search results owned separately by the TUI and core. Switching WPE from text to graphics could send `Next` to an engine that never received `Search`, or leave old native highlights uncleared. Define the effective search provider for the current presentation, report results through a common document/search-scoped browser event, and reset or restart searches on provider changes. The existing `page_input` hook already has an event queue; the proposed hook omits it. See [frontend.rs:90](/home/gusahlg/repos/sighurt/crates/sighurt-runtime/src/frontend.rs:90) and [session.rs:252](/home/gusahlg/repos/sighurt/crates/sighurt-runtime/src/session.rs:252).

9. **Medium — The history title and visit rules assume information the current events do not provide (lane C).**  
   `TitleChanged` has no document generation. “The first title of that document” therefore needs a stronger event contract or proven adapter ordering; the current commit handler also does not clear the old title. A title-only *upsert* arriving after `history.clear` can recreate the deleted visit. Make title updates modify an existing visit associated with a specific accepted commit, with deletion invalidating that association. Separately define visits for reloads, traversal, background navigation, `pushState` and `replaceState`: all can commit, and counting every same-document commit lets a page inflate counts or evict useful history. See [events.rs:82](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/events.rs:82), [events.rs:127](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/events.rs:127), and [state.rs:1904](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/state.rs:1904).

10. **Medium — “Private because 0600” is an incomplete history policy (lane C).**  
    The scheme blacklist still admits local file paths and arbitrary configured schemes; HTTP URLs can contain credentials or sensitive queries/fragments. A 5,000-entry cap limits count, not retention age. Default-on history also creates a new persistence setting that must be included in the documented privacy recipe. Define URL eligibility, credential handling, retention, and startup/live-disable behavior—including clearing loaded completion data and pending writes. Use the engine’s effective launched storage settings. Explicitly disable history for `--dump`: it shares the runtime and currently opts out of persistence through `Paths { session: None }`. See [privacy documentation](/home/gusahlg/repos/sighurt/docs/rewrite/extension-api.md:387), [launched settings](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/state.rs:440), and [dump.rs:274](/home/gusahlg/repos/sighurt/frontends/sighurt-tui/src/dump.rs:274). Document that visited history, saved tabs and reopen records are distinct retention scopes.

11. **Medium — Inferring find mode from `/` breaks existing addresses and leaves the search lifecycle awkward (lanes A/B).**  
    Absolute paths already start with `/`; typing `/tmp/page.html` would become a search. Decision 19 establishes `:` commands, not `/` reservation. An explicit editor mode, entered by a named command, avoids this ambiguity while still displaying `/` as a prompt. Define bare `/`, deleting the last character, leaving the mode, tab changes, paste and IME commits. Enter currently advances past the match incremental search already selected and keeps focus in the editor; Escape stops the search, so the ordinary keyboard exit leaves nothing for NORMAL `n`/`N` to continue. Prefer Enter accepting the current match and returning focus, with closing the field distinct from clearing search state. Also resolve “cut” versus “refused” overlong queries and whether whitespace is searchable. See [router.rs:188](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/router.rs:188) and [chrome submission](/home/gusahlg/repos/sighurt/ui/sighurt-ui/src/chrome.rs:788).

12. **Medium — Completion needs editor-session validity and exact acceptance semantics (lane C).**  
    “Ignore older request IDs” is insufficient when closing the editor, changing tabs, entering `:`/find mode, clearing history, or disabling completion produces no newer request. Invalidate outstanding replies and ghost text on those transitions, as paste already does. Scheme/`www.`-stripped matching also does not define an appendable suffix: accepting `https://www.example.com/` after typing `example` requires a precise replacement rule. Preserve an explicitly typed scheme and path semantics. Keep the exact navigable URL separate from contained display text; sanitizing or truncating an actionable URL can change its destination. Accept only on an eligible caret/selection state. Shared completion data must remain independent of `sighurt-ui`, which neither runtime nor TUI may depend on. See [paste lifetime handling](/home/gusahlg/repos/sighurt/ui/sighurt-ui/src/chrome.rs:561), [containment](/home/gusahlg/repos/sighurt/ui/sighurt-ui/src/extension.rs:285), and [dependency rules](/home/gusahlg/repos/sighurt/CLAUDE.md:100).

13. **Medium — Terminal behavior needs its own explicit limitations (lanes B/D).**  
    Searching independently over reflowed lines makes matches depend on terminal width and misses phrases crossing soft wraps. Search logical text with positions mapped to rendered lines; refresh positions when snapshots or layout change. `DocumentGeneration` alone does not identify successive semantic snapshots of the same document, and snapshots can be truncated, so “no matches” may only mean none in the extracted content. Window fullscreen cannot be truthfully acknowledged by merely hiding terminal rows: define that as a terminal presentation mode, or report window fullscreen unsupported. Preserve an editor/notice row and handle page metrics and graphics placement consistently. See [TextView::retarget](/home/gusahlg/repos/sighurt/frontends/sighurt-tui/src/textmode/view.rs:189), [semantic snapshot limits](/home/gusahlg/repos/sighurt/crates/sighurt-api/src/semantic.rs:29), and [terminal chrome layout](/home/gusahlg/repos/sighurt/frontends/sighurt-tui/src/chrome.rs:95).

14. **Medium — Count bounds do not establish acceptable memory or I/O bounds (lanes A/C).**  
    Ten full `SessionTab` records can retain roughly 2 GiB of URL history under the existing 50-segment and 4-MiB-per-segment limits. Give the reopen stack a total byte budget, or initially retain only the address, engine and zoom. Likewise, enforce a history-file byte limit *before* TOML parsing; copying `Session::parse` only bounds retained entries after parsing. The session writer uses an unbounded channel and drains to the latest snapshot—it is not a bounded one-slot mailbox. Avoid accumulating serialized history snapshots behind slow storage. See [navigation limits](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/navigation.rs:54), [Session::parse](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/session.rs:90), and [SessionWriter](/home/gusahlg/repos/sighurt/crates/sighurt-runtime/src/persistence.rs:419).

15. **Medium — Tab commands need observable semantics beyond vector operations (lane A).**  
    Preserve existing no-argument `tab.new` focus behavior, and specify focus for the address-taking form. Define whether duplication preserves an explicitly chosen engine and zoom; copying only the URL can reopen the page in another engine. Check `MAX_TABS` before consuming a reopen record. Record only successful closes—the last-tab guard currently makes some closes no-ops—and decide whether page-initiated closures enter the reopen stack. Preserve selected tab identity during moves. Extract a single-tab save helper rather than cloning the entire session to close one tab. See [command semantics](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/commands.rs:4), [close_tab](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/state.rs:1048), and [chosen-engine semantics](/home/gusahlg/repos/sighurt/crates/sighurt-core/src/tabs.rs:253).

Before implementation, I would revise the contracts first: explicit find-editor mode; document-scoped search operations with one result path for engines and terminal text; a bounded history store with acknowledged deletion and defined second-instance behavior; and fullscreen state that preserves browser controls. I would implement window fullscreen before page fullscreen, keeping each engine’s page capability false until denial and exit work demonstrably. Acceptance cases should include reordered results, navigation during search, text/graphics switches, clear followed by late titles, two simultaneous instances, and fullscreen Escape press/release across focus changes.
